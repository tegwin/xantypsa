# Xanty PSA

Open source Professional Services Automation, designed specifically for smaller
MSPs. Service desk, CRM, contracts, quoting, invoicing, projects and time, that
you self-host and own outright.

- **Website:** [xanty.net](https://xanty.net)
- **Source:** [github.com/tegwin/xantypsa](https://github.com/tegwin/xantypsa)
